# VOLTA — магазин электроники

Минималистичный анимированный сайт-витрина магазина электроники с реальными моделями: iPhone 17, Galaxy S25 Ultra, Pixel 10 Pro, MacBook, iPad, AirPods и другими. Устройства нарисованы в SVG и перекрашиваются при выборе цвета. Цены ориентировочные.

## Возможности

- Анимированный hero: печатающийся заголовок, 3D-наклон телефона, плавающие «блобы», орбиты, счётчики
- Каталог с фильтрами по категориям, поиском и сортировкой
- Корзина (сохраняется в `localStorage`) с анимацией «полёта» товара
- Быстрый просмотр товара, избранное
- Акция недели с обратным отсчётом
- Светлая и тёмная тема, адаптивная вёрстка, поддержка `prefers-reduced-motion`

## Запуск

Без сборки и зависимостей — просто откройте `index.html` в браузере
или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Структура

```
index.html     — разметка
css/style.css  — стили и анимации
js/main.js     — данные товаров и логика
```
