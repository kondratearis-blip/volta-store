# Kokoro — заказы с сайта

Минималистичный сайт для заказа комбо с доставкой и админка для менеджеров.
Клиент собирает корзину и оформляет заказ, а после оформления видит QR-код для оплаты.
Менеджер видит заказ в админке, пишет клиенту в WhatsApp одной кнопкой (текст с составом заказа уже подставлен) и ведёт статусы.

- `/` — страница заказа для клиентов
- `/admin` — админка: заказы, меню, настройки (доставка, минимальная сумма, QR-код, шаблон сообщения WhatsApp)

## Как устроено

- `public/` — статичные страницы (без сборки)
- `netlify/functions/api.mjs` — серверная функция Netlify, все запросы `/api/*`
- `lib/api.mjs` — логика API; данные хранятся в Netlify Blobs (отдельная база не нужна)
- Цены на сервере берутся из меню, поэтому подменить сумму из браузера нельзя

## Запуск на Netlify

1. Netlify → **Add new site → Import an existing project** → выбрать этот репозиторий.
   Чтобы заменить текущий сайт `kokoro-kgz.netlify.app`, в его настройках откройте
   **Site configuration → Build & deploy → Link repository**.
2. **Site configuration → Environment variables** → добавить `ADMIN_PASSWORD` (пароль для входа в админку).
3. Deploy. Затем откройте `/admin`, войдите, заполните меню и загрузите QR-код в «Настройках».

## Локальный просмотр

```bash
npm install
ADMIN_PASSWORD=secret npm run dev   # http://localhost:8888 и http://localhost:8888/admin
```

Локально данные сохраняются в папку `.data/`.
