# KOKORO — заказы на сайте

Минималистичный сайт KOKORO только для заказов, без переписки:

1. Клиент выбирает количество комбо, оставляет адрес и телефон → «Перейти к оплате».
2. Видит QR-код и сумму, оплачивает в приложении банка и прикрепляет чек.
3. Видит «Заказ принят». Менеджер получает заказ с чеком в панели, пишет клиенту в WhatsApp одной кнопкой и ведёт статусы.

Если клиент ушёл в банк и вернулся на сайт, страница сама откроет шаг оплаты его заказа.

- `site/index.html` — страница заказа
- `site/admin.html` — панель менеджера: заказы за день (обновляются каждые 10 секунд, звук при оплаченном заказе), чек, статусы, заметки, настройки (QR-код, цена комбо, доставка, приём заказов вкл/выкл, шаблон сообщения WhatsApp)
- `supabase/orders.sql` — таблицы, функции и хранилище (чеки, QR-код) для базы Supabase

Данные — в той же базе Supabase, что и у старого сайта (`site/assets/js/config.js`). Вход в панель — теми же почтой и паролем, что и в старую панель (таблица `admins`).
Сумму заказа считает база (функция `place_order`), подменить цену из браузера нельзя. Читать заказы могут только администраторы.
Статусы: «Ждёт оплаты» (оформил, чек ещё не прислал) → «Оплачен — новый» (чек приложен) → Подтверждён → Готовится → В пути → Доставлен / Отменён.
Чеки лежат в закрытом хранилище `receipts`: загрузить чек можно только к своему неоплаченному заказу, смотреть — только администраторам.

## Запуск

1. **База.** Supabase → SQL Editor → вставить `supabase/orders.sql` целиком → Run. Один раз; повторный запуск безопасен.
2. **Сайт.** Опубликовать папку `site/` на Netlify:
   - вручную: заархивировать содержимое `site/` и загрузить в Netlify → Deploys (как раньше);
   - или подключить этот репозиторий к сайту (Site configuration → Build & deploy → Link repository) — `netlify.toml` уже указывает папку `site`.
3. Открыть `/admin.html`, войти → «Настройки» → **Загрузить QR-код** (картинка QR из приложения банка), проверить цену и доставку, сделать тестовый заказ.

## Что поменять без программиста

- Состав комбо, телефон, Instagram — `site/assets/js/data.js`
- QR-код, подсказка под ним, цена, доставка, приём заказов, текст сообщения WhatsApp — в панели, вкладка «Настройки»
