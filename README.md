# VOLTA — магазин электроники

Сайт-витрина магазина техники в стиле банковского приложения: серый фон, белые карточки, истории, промо-баннеры, плитки категорий, цены с ежемесячным платежом и калькулятор рассрочки.

В каталоге реальные модели: iPhone 17, Galaxy S25 Ultra, Pixel 10 Pro, MacBook, iPad, AirPods, Sony, Apple Watch, PS5 Pro, Switch 2 и другие. Устройства нарисованы в SVG и перекрашиваются при выборе цвета. Цены ориентировочные.

## Возможности

- Истории (как в банковских приложениях) с автопрокруткой и паузой по удержанию
- Промо-баннеры с перелистыванием и категории-плитки
- Каталог с фильтрами, поиском, сортировкой и избранным
- Отдельная страница товара (`#id-товара`): цвета, конфигурации, «Сразу / Частями», характеристики, похожие товары
- Корзина-шторка с оплатой сразу или в рассрочку; фон под ней не прокручивается
- Калькулятор рассрочки, FAQ, нижнее меню на телефоне, светлая и тёмная тема

## Запуск

Без сборки и зависимостей — откройте `index.html` или запустите `python3 -m http.server 8000`.

## Структура

```
index.html      — разметка
css/style.css   — стили
js/devices.js   — SVG-модели устройств
js/data.js      — товары, цвета, конфигурации
js/app.js       — интерфейс: истории, каталог, страница товара, корзина
```
