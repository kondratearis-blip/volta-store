# KOKORO — заказы на сайте

Минималистичный сайт KOKORO только для заказов: клиент выбирает количество комбо, оставляет адрес и телефон и оформляет заказ без переписки. Менеджер видит заказ в панели, пишет клиенту в WhatsApp одной кнопкой (текст с номером заказа, суммой и адресом уже набран) и ведёт статусы.

- `site/index.html` — страница заказа
- `site/admin.html` — панель менеджера: заказы за день (обновляются каждые 10 секунд, звук при новом заказе), статусы, заметки, настройки (цена комбо, доставка, приём заказов вкл/выкл, шаблон сообщения WhatsApp)
- `supabase/orders.sql` — таблицы и функция заказов для базы Supabase

Данные — в той же базе Supabase, что и у старого сайта (`site/assets/js/config.js`). Вход в панель — теми же почтой и паролем, что и в старую панель (таблица `admins`).
Сумму заказа считает база (функция `place_order`), подменить цену из браузера нельзя. Читать заказы могут только администраторы.
Оплата по QR пока не подключена: клиент выбирает «наличными курьеру» или «переводом», менеджер уточняет в WhatsApp.

## Запуск

1. **База.** Supabase → SQL Editor → вставить `supabase/orders.sql` целиком → Run. Один раз; повторный запуск безопасен.
2. **Сайт.** Опубликовать папку `site/` на Netlify:
   - вручную: заархивировать содержимое `site/` и загрузить в Netlify → Deploys (как раньше);
   - или подключить этот репозиторий к сайту (Site configuration → Build & deploy → Link repository) — `netlify.toml` уже указывает папку `site`.
3. Открыть `/admin.html`, войти, проверить цену и доставку во вкладке «Настройки», сделать тестовый заказ.

## Что поменять без программиста

- Состав комбо, телефон, Instagram — `site/assets/js/data.js`
- Цена, доставка, приём заказов, текст сообщения WhatsApp — в панели, вкладка «Настройки»
