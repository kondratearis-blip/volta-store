# Исправление проверки чеков KOKORO (26.11.2026)

Патч для репозитория `kondratearis-blip/kokoro-live` (основа — коммит `f36d5c9` в `main`).
Сюда положен потому, что у облачной сессии не было права записи в `kokoro-live`.

Что внутри:
- проверка времени в чеке: запас 2 минуты вместо 15 (подставной чек на 14 минут раньше заказа больше не получает «✓»);
- в панели: «Новый» заказ с чеком «✗» или ещё не сверенным принимается (статус или курьер) только после вопроса
  «Деньги пришли — принять заказ?»;
- в карточке «Чек приложен в …» без «✓», рядом время из чека и время загрузки;
- тесты и документация. База данных не меняется.

Как применить (в папке `kokoro-live` на ноутбуке):

    git checkout -b claude/receipt-time-gate
    git am /путь/к/0001-receipt-time-gate.patch
    node scripts/test-receipt-check.mjs

Потом слить в `main` и выложить: `node scripts/deploy-cloudflare.mjs`.
