# Фото и видео квартир

Сюда кладите фото интерьеров, видео-обзоры и фото вида из окна (jpg/webp/mp4).
Затем впишите пути в объект `MEDIA` (или `PROJECT_MEDIA` для конкретного ЖК) в `index.html`.

Рекомендации: фото — 1600×1000 px, webp/jpg до 400 КБ; видео — mp4 (H.264), до 15 МБ, или ссылка YouTube embed.
